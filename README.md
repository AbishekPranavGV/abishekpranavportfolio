## Get started

```bash
npm install
npm run dev
```

Open the local Vite URL shown in your terminal.

## Quality checks

```bash
npm run build
npm test -- --passWithNoTests
```

GitHub Actions runs these checks for pushes and pull requests targeting `main`. The existing lockfile currently needs to be regenerated; use `npm install` rather than `npm ci` until it is synchronized.

## Deploy

Connect `AbishekPranavGV/abishekpranavportfolio` to a static hosting provider with repository permissions. Vite build command: `npm run build`; output folder: `dist`. Publish only after the build passes. Your hosting provider requires separate authorization; a GitHub commit is not itself a live deployment.
